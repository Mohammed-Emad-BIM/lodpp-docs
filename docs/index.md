# LOD++

LOD++ is a Revit add-in for information, geometry, audit, and system work. Each command has a procedure on this site. In Revit, **?** on that command opens the same page.

Start with [Using LOD++](using-lodpp.md), then open the command you are running.

## Information++

| Command | Purpose |
|---------|---------|
| [Locate](docs/information/locate.md) | Write room, level, coordinate, and grid values to parameters |
| [Populate](docs/information/populate.md) | Queue parameter writes, review them, then apply |

## Geometry++

| Command | Purpose |
|---------|---------|
| [Split](docs/geometry/split.md) | Create one element per compound layer |
| [Track](docs/geometry/track.md) | Review drift against the archived Split source |
| [Parts](docs/geometry/parts.md) | Divide hosts into parts |
| [Quick Actions](docs/geometry/quick-actions.md) | Offset floor, roof, and ceiling profiles |

## Audit++

| Command | Purpose |
|---------|---------|
| [Purge++](docs/audit/purge.md) | Delete unused items after a category preview |
| [Rename](docs/audit/rename.md) | Rename families, types, sheets, and views |
| [Pin](docs/audit/pin.md) | Pin or unpin with Revit's native pin |
| [Audit Parameters](docs/audit/parameters.md) | Review unused and low-use parameter bindings |

## System++

| Command | Purpose |
|---------|---------|
| [Warnings](docs/system/warnings.md) | Browse persistent warnings and zoom to an element |
| [Find & Replace](docs/system/find-replace.md) | Replace text notes after a preview |
| [Find](docs/system/find.md) | Resolve ElementId and UniqueId values |
| [Transfer](docs/system/transfer.md) | Copy missing standards from another project |
