# Quick Actions

Offset floor, roof, and ceiling boundaries inward or outward.

**Ribbon:** Geometry++ → Quick Actions  
**In Revit:** header **?** opens this page.

## Workflow

1. Set the scope and analyze eligible elements.
2. Choose the offset and whether the edit stays on the same element or creates a new tracked element.
3. **Apply**.

Profiles store the presets you reuse.

## License

Analyze is available before apply. Creating new tracked elements is **Pro**. Locked rows stay locked until the license allows them.
